# Problem Statement

#### 13. Steganography Tool for Image/File Hiding

1. Objective: Hide text or files inside images using steganography.
2. Tools: Python, PIL, stepic, tkinter
3. Mini Guide:
    * Convert message to binary and embed in image LSB.
    * Allow uploading image + hidden message.
    * Extract and decrypt (optional) from modified image.
    * Add drag-and-drop GUI.
    * Support image formats like PNG, BMP.
4. Deliverables: GUI tool for embedding and extracting data from images.
