# Problem Statement
### 10. Secure Chat App with End-to-End Encryption

1. Objective: Create a private chat application with E2EE using public-key cryptography.
2. Tools: Python, Flask-SocketIO, RSA/AES from cryptography
3. Mini Guide:
   * Generate RSA keys per user and share public keys.
   * Encrypt messages with AES, keys shared via RSA. 
   * Create real-time communication with Flask-SocketIO. 
   * Store chat logs encrypted on server (optional). 
   * Display messages decrypted only on client side.
4. Deliverables: Secure chat app with E2EE and encrypted logs.
