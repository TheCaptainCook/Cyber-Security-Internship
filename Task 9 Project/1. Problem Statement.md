# Problem Statement

### 4. Password Strength Analyzer with Custom Wordlist Generator
1. Objective: Build a tool to analyze password strength and generate custom wordlists.
2. Tools: Python, argparse, NLTK, zxcvbn
3. Mini Guide:
   * Analyze user password using zxcvbn or custom entropy calculations.
   * Allow user inputs (name, date, pet) to generate a custom wordlist.
   * Include common patterns like leetspeak, append years.
   * Export in .txt format for cracking tools.
   * Add GUI with tkinter or CLI interface.
4. Deliverables: Tool that evaluates password strength and exports attack-specific wordlists
